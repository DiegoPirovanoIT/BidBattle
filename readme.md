# BidBattle

BidBattle è un videogioco multiplayer in cui due o più giocatori si sfidano a indovinare il prezzo di prodotti casuali trovati su eBay, tramite la API di eBay.

## Stato del progetto

Il progetto è appena iniziato: non c'è ancora codice.

## Configurazione

Le credenziali della API di eBay vanno tenute in un file `.env`, che è escluso dal repository.
